# Recherche: Parasitenschutz vs. Impfung – alle 14 Tierarten

**Datum:** 11.07.2026
**Zweck:** Fachliche Klärung ob es bei irgendeiner Tierart eine Impfung gegen Parasiten gibt, oder ob Parasitenschutz immer nur Medikament/Behandlung ist.

## Kernaussage

**Es gibt bei KEINER der 14 unterstützten Tierarten eine Impfung gegen Parasiten (Würmer, Zecken, Flöhe, Milben).** Parasitenschutz ist IMMER ein Medikament (Anthelminthikum, Akarizid, Spot-On, Tablette, Halsband) – keine Impfung.

Einzige Ausnahme im weitesten Sinne: Die **Borreliose-Impfung** beim Hund schützt vor einer durch Zecken ÜBERTRAGENEN Krankheit – aber nicht vor dem Zeckenbefall selbst. Das ist eine echte Impfung und gehört unter Impfstatus.

## Ergebnisse pro Tierart

### Tierarten MIT Impfmodul (vaccinations)

| Tierart | Echte Impfungen (→ Impfstatus) | Parasitenschutz (→ eigener Block) |
|:---|:---|:---|
| Hund | Tollwut, Staupe, Parvo, Lepto, Borreliose | Wurmkur, Zecken-Spot-On/Tablette/Halsband, Flohschutz |
| Katze | Tollwut, Katzenseuche, Katzenschnupfen, FeLV | Wurmkur, Zecken-/Floh-Spot-On, Ohrmilben-Behandlung |
| Kaninchen | Myxomatose, RHD1, RHD2 | Kokzidien-Behandlung, Milben (Ivermectin), Flöhe |
| Frettchen | Staupe, Tollwut | Flöhe, Ohrmilben, Wurmkur |
| Pferd | Tetanus, Influenza, Herpes, Tollwut | Wurmkur (selektive Entwurmung), Zecken, Milben |

### Tierarten OHNE Impfmodul

| Tierart | Impfungen? | Parasitenschutz relevant? |
|:---|:---|:---|
| Meerschweinchen | Keine Standardimpfung | Ja: Milben (Grabmilben!), Haarlinge, Flöhe |
| Chinchilla | Keine Standardimpfung | Ja: Pelzmilben, Haarlinge |
| Ratte | Keine Standardimpfung | Ja: Milben, Haarlinge |
| Maus | Keine Standardimpfung | Ja: Milben |
| Degu | Keine Standardimpfung | Ja: Milben, Haarlinge |
| Hamster | Keine Standardimpfung | Ja: Milben, Haarlinge |
| Ziervogel | Keine Standardimpfung (Ausnahme: Psittakose bei Zucht) | Ja: Rote Vogelmilbe, Federlinge, Luftsackmilben |
| Reptil | Keine Standardimpfung | Ja: Würmer (Fenbendazol), Milben, Zecken (bei Freiland) |
| Aquarium | Keine | Nein (Fischparasiten = eigene Kategorie, nicht vergleichbar) |

## Schlussfolgerung für den Notfallpass

1. **Parasitenschutz als eigener Block ist für ALLE Landtiere relevant** – nicht nur für Hund/Katze.
2. **Bei Tierarten OHNE Impfmodul** (Meerschweinchen, Chinchilla, Ratte etc.) gibt es trotzdem Parasitenschutz – dieser wird aktuell vermutlich unter "Medikament/Pflege" erfasst (E-53).
3. **Im Notfallpass** sollte der Block "Parasitenschutz" für alle Tierarten angezeigt werden, die Parasitenschutz-Einträge haben – unabhängig davon ob sie ein Impfmodul haben.
4. **Aquarium** ist die einzige Ausnahme – dort ist Parasitenschutz nicht sinnvoll im Notfallpass.
